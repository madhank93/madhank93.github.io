Not a queue — a shape. Go and Kubernetes are separate starting points, and each later step only assumes the ones its arrows come from.

  1. Start at either end
    • Golings Go, exercise by exercise
    • Kubelings Kubernetes, hands on no Go needed — kubectl and YAML
  2. Then build with it
    • BYOX build Redis, Git, a shell after Golings
    • KubeClientlings client-go and controllers after Golings + Kubelings
  3. Then go deeper
    • System design caching, consistency, partitioning after BYOX — you have built the thing being scaled In progress
    • byok8s build kubectl and the control plane after KubeClientlings In progress
  4. Then break it and fix it
    • DevOpsLings debug what is already broken after Kubelings — sharper with the rest In progress
